# 📊 API Resources Game Updater (Excel)

Скрипт для получения данных из API игры Resources и формирования отчёта в формате Excel.

# 🔧 Возможности

- Получение данных из API (шахты, заводы, склады, рынок и т.д.)
- Расчёт производства и потребления ресурсов
- Расчёт суточного баланса
- Расчёт прибыли (оценка)
- Генерация Excel-отчёта
- Автоматическая отправка отчёта в Telegram
- Архивация старых отчётов

# ⚙️ Установка

1. Клонировать репозиторий или скачать архив:

git clone <ссылка>

2. Установить зависимости:

pip install -r requirements.txt

# 🛠️ Настройка

Открой файл "config.py" и укажи:

- "API_KEY" — ключ API игры
- "BOT_TOKEN" — токен Telegram-бота
- "CHAT_ID" — ID чата для отправки сообщений

Также можно настроить:

- таймауты соединения
- количество повторных запросов
- пути для сохранения файлов

# ▶️ Запуск

python main.py

# 🤖 Автоматизация

Можно запускать через cron (Linux) или планировщик задач (Windows).

Пример cron (раз в 3 дня):

0 12 */3 * * /путь/к/python /путь/к/main.py

# 📁 Структура проекта

- "main.py" — точка входа
- "api_client.py" — работа с API
- "report_runner.py" — сбор данных
- "*_excel_builder.py" — генерация Excel
- "profit_calculator.py" — расчёты прибыли
- "config.py" — настройки

# ⚠️ Важно

- Не публикуйте реальные API ключи и токены
- Используйте "config.example.py" для примера

# 📌 Примечание

Расчёты прибыли являются оценочными и могут отличаться от фактических значений в игре.
